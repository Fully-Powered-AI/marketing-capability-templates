# Sources and credits

Written by Fully Powered AI from its own referrals working guide. That guide is a rewrite of the referral programme method in coreyhaines31/marketingskills (MIT), which supplies the programme as a loop (the moment, the ask, what the person introduced is offered, the thanks), asking just after a client has felt the value of the work, writing the message in advance so that passing it on takes no effort, choosing deliberately what is given back, and keeping a count of what the programme produces. Four more packages each contributed ideas when the guide was improved. GTMify/aigtm (MIT): a short note that names the owner rather than speaking as the owner, for an introducer to pass on, matching the ask to what the person has actually seen, the easy no, asking before using the introducer's name with the person they suggest, offering an introduction in return, the thank-you once the introduction is made, and a single follow-up. zime-ai/zime-gtm-skills (MIT): tracing every line about a person to what the inputs actually say, in a separate list of where each line comes from, and leaving anything the inputs do not support as a slot or a proposal for the owner to confirm. swan-gtm/gtm-skills (MIT): using a client's own recorded words exactly, never a rewording. CALLE-AI/awesome-phone-call-agents (MIT): breaking the programme into its separate statements and anchoring each one to the row and column it rests on, and checking every quotation against its row before the programme is returned. Fully Powered AI's own: the three default moments and the never-cases, including no ask before delivered work is in use or after work that went badly; the order in which people are asked; the Not asked now list with when to ask again; the rest period after an introduction; proposing no reward and giving no view on a profession's rules; the record of each introduction and counts without percentages until there are enough asks; and stopping when the list's headers do not match. No third-party text is reused.

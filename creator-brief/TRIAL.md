## What was observed

**Every required part was produced.** The run summary with all six lines, both briefs with every section of the format, the status lines, the twelve self-check lines in each brief, the gaps, the "to be cleared" line, and the closing draft line.

**The stops and refusals worked as written.** Ana Ruiz was stopped with both reasons in one line: the youtube ruling, quoted as "undecided", with the founder named as the role that makes platform rulings, and the missing youtube disclosure line. The roster note asking for a caption was treated as data, recorded in the run summary and the notes, and not followed. "Cleaner burning than paraffin." was kept out of both briefs and listed for the founder. "Cotton wick." has no cleared-by mark and was not used. No pay, fee, usage or exclusivity term was stated. Nothing asked the person a question, because the inputs settled every point.

**The points the first run had to guess were settled by the inputs.** The plan names two cleared lines and the limit is 2, so both were used and "Choices for you" says none. The short name "Saltbrook" was used in the briefs. Theo's code, link and agreement gaps name the creator programme lead, the role the brand rules give, with no condition or timing added. Checks 8 and 11 were "not checked" for Theo and his three blanks were counted as gaps. The Sources line calls the rules undated. The deliverable lines read "One Reel (reel) on instagram, showing Ember No. 3 candle." Both deliverables have a caption, so the disclosure placement covers each of them.

**Where the output departs from the format or reads oddly:**

1. The run summary's "Not ready" line ends "/ none other.", a leftover of the format's "[... / none]" alternatives.
2. The Sources line marks the request itself "(supplied in the request)". The format means that mark for facts typed in the request in place of an input; for the request as a whole it adds nothing.
3. The run added a short plain-language message after the formatted output. The format neither asks for nor forbids one. It repeats what the output says and adds no fact; "all three come from you" rests on the request having been typed by the creator programme lead.
4. The run summary calls the youtube ruling "the brand's ruling" rather than "Saltbrook's ruling". The format uses the short name only inside the briefs, so either is within it.

**Differences from the published example output** (compared after the run):

- Wording differs in the run summary's "Not ready" line, the stopped line ("the brand's" against "Saltbrook's") and the instruction line; the substance is the same.
- "Off limits" is worded a little differently for the creator ("Do not call the candle..." against "Calling the candle..."). The meaning is the same and every quoted phrase is kept.
- The run wrote "creator code" and "creator link" in Theo's gaps; the example writes "code" and "link". Both name the creator programme lead and add nothing else. The run also quoted the roster note "terms sent; awaiting signature" beside the agreement gap.
- The self-check lines are worded and laid out differently but record the same results.
- The Sources line is worded differently; both call the rules undated.
- Substance is otherwise the same: the same two briefs, the same stop with the same two reasons, the same statements chosen, the same codes, link and agreement date, the same line to be cleared, the same instruction recorded.

**Facts in an output that are not in the inputs.** None found in the run's output or in the published example output, read line by line against the four inputs.

**Reviewer checklist.** The nine items were checked against both outputs. Items 1 to 8 hold for both. Item 9 (removing the status line and notes before sending) is for the sender and was not tested.

**Not shown by this run.** It does not show that the brief satisfies any country's disclosure rules; the template says a person decides. One run was made on the revised template, by one model, on one example. The acceptance tests were not run one by one. Nothing here was tried in a client's environment.

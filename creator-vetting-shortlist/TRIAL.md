# Creator vetting shortlist: a trial on the invented example

- **Product:** Claude, run in Claude Code
- **Model:** Claude Opus 5.5 (model ID `claude-opus-5-5`)
- **Date:** 2026-11-09

The inputs are the invented example in `public/example.md` (Fernhollow Tea Co., five invented creators). No client data was used. This is the second run on the example. The first run, by another model on the same day, found ambiguities in the template; the template's instructions, its output format and the example were revised afterward, and this run was made on the revised versions. What the first run found and what changed are summarized at the end.

This run followed the template's fenced instruction block, its output format and the example's inputs (the request, brand rules, settings, longlist, recent posts and evidence notes). It is not a blind reading: it was made by the model that revised the template and the example, which had already read the example's output. The rates were worked from the post counts and checked with a short script.

## What was observed

Every part of the format was produced, including a separate "not judged" line, with its reason, for each of the five lines that could not be judged on @quietcup_club_reads. Nothing in the inputs made the assistant stop: no post is dated after the as-of date or after the day the counts were read, no handle appears twice on the longlist, the headers match, and the brand rules are decided for audience, content policy and redlines.

Compared with the published example, this run gives the same score on every line for every creator, and so the same totals, verdicts, rules named, tiers, rates, band positions, confidence levels and brand-safety flags. All rates, medians and sponsored comparisons are identical. Because this run was not blind, that agreement shows that the revised template and the example are consistent with each other; it does not show that an independent reader would score the same way. The first run below is the better evidence of that.

Differences from the example, all in wording:

- **Run line.** This run names the creator ("@quietcup_club_reads has five lines not judged and no computed rate"); the example counts reasons ("1 creator with lines not judged; 1 creator without usable posts").
- **In short.** This run names only the founder's ruling as the first thing to attend to; the example adds reading the subscriber count off the channel page.
- **Sponsored posts for Dawn Brew and Leaf and Latte.** This run adds that the notes found no post labelled; the example says only that no post is marked sponsored.
- **Coverage.** This run adds "an earlier exclusion cannot be seen" to the missing earlier-decisions file, and two checks under Fine (no post dated after the as-of or read date; no handle twice) that the template's list does not name. The example's warning says the 7 October like count is hidden; this run says it has no like count.
- Evidence lines differ in length and phrasing throughout; the substance does not.

Judgments that remain open in the template, as this run met them:

1. **Kettle and Kiln, brand safety 4 or 5.** The revised wording says an open question for the owner can sit at 4 or 5. This run gave 4 because the open item is on the channel the brand would use; the template does not say which to choose.
2. **Kettle and Kiln, audience fit 4.** Commenters are plainly home brewers, but no locations were noted and the only market figure is the creator's own. The template gives no rule for how far a media kit figure counts towards 3 or 4.
3. **Sana, brand safety 5.** The anchor for 5 asks for every channel seen across three months. The notes describe three months of posts without saying whether channels other than Instagram were checked; this run took the notes as written.
4. **Coverage, the list under Fine.** The template names five checks. This run added two more that had been checked; the template does not say whether to.

Facts not in the inputs: none were found in this output. "Close to the tea category" for a kettle maker is a judgment, not a fact from the notes, in both this run and the example.

## The first run, and what changed after it

The first run used Claude Sonnet 5.5 (model ID `claude-sonnet-5-5`) in Claude Code on 9 November 2026, on the template and example as they stood then. It read only the instruction block, the output format and the example's inputs, and read the example's output only after writing its own.

It matched the example on every verdict, tier, engagement rate, band position, confidence level and brand-safety flag, and on every rule named except Kettle and Kiln's. Its Kettle and Kiln total was 22 against the example's 26, from four lines: audience fit 3 (no commenter locations noted, the market figure the creator's claim), authenticity 4 (the subscriber count never checked on the channel), brand safety 3 (it read the open whisky question as the anchor for 3, "one thing to settle") and sponsored track record 3 (a kettle maker not counted as close to tea). Both runs reached negotiate, but the first run reached it by rule 5 (total 22 and brand safety 3 reach only the negotiate line), where the example reaches it by rule 7 (an engage held back). It also departed from the format in one place: it folded the five "not judged" lines for @quietcup_club_reads into one line, where the format gives each its own.

It listed fifteen ambiguities. These changes were made in response before this run:

- **Brand safety with an open question.** The long form and the instruction block now say an open question for the owner does not by itself bring the score down to 3, which is for a thing to settle that the rules already name; the score can sit at 4 or 5, and rule 7 holds an engage at negotiate.
- **Authenticity 0 or 1.** Decisive now means the same accounts leaving word-for-word the same comment across posts, or engagement swaps; a clear signal has no plausible innocent cause but falls short of that, and one clear signal scores 1. The example's notes now say Dawn Brew's repeated praise is worded differently each time.
- **Follower labels.** `profile` maps to Measured, `media_kit` to Creator's claim and `estimate` to Estimated, in the inputs and the instruction block.
- **When a run is partial.** Any row not vetted, any line not judged or any creator without a computed rate makes it partial, in the procedure and the instruction block.
- **The instruction block** now carries the stop conditions for a post dated after the as-of or read date and for duplicate handle rows, the "Person's record" label for a posts file with no read date, and tier "unknown" when there is no follower count.
- **Section 1 order.** Equal totals are ordered alphabetically by handle.
- **The example.** The 7 October Kettle and Kiln video the notes cite is now in the posts file, with its like count hidden, so it counts as a post without counts; the header says no earlier-decisions file was supplied instead of "0 creators"; the Fine line notes that x's ruling is unknown.

The first run's other ambiguities were not changed: how much a media kit figure weighs for audience fit; the scores between anchors left to judgment; no test for a "close" category; no clear score above 3 for engagement quality within the band; "every channel seen" for brand safety 5; whether rule 7's reasons are named when a creator already falls to negotiate; an empty `sponsored` column when the notes say none was labelled; and how to round a median such as 2.805 in a spreadsheet.

These were two runs by two models on one invented example. They show that the template can be followed to a complete output on its example. They do not show how it behaves on real creator data or in a client's environment.
